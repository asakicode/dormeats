# DormEats 디자인 리프레시 설계

- 날짜: 2026-10-26
- 상태: 빌더 검토 반영 완료, 사용자 최종 승인 대기
- 데모(참고용 HTML): `.superpowers/brainstorm/825990-1792979112/content/` 의 `demo-v2.html`, `date-nav.html`, `menu-layout.html`, `wish-top.html`, `badge.html`

## 배경과 목적

면접에서 이 앱을 보여줬을 때 받은 피드백: **"누가 봐도 Claude(AI)가 만든 티가 난다."** 지적된 건 색, 폰트, 이모티콘.

원인은 AI가 기본으로 내놓는 조합을 그대로 쓴 것:

- 크림/베이지 배경 + 차분한 포인트 한 색(이전엔 황토, 지금은 숲색 초록) — Claude.ai 자체 팔레트와 같은 공식
- 제목은 감성 서체(Gowun Dodum, `font-serif`), 본문은 고딕
- 아이콘 대신 이모지(❤️ 🤍 🔥 📌 🍚 😢), 그것도 Lucide 선 아이콘과 섞여서
- 둥근 색 카드, 점선 빈 상태 박스, 기울어진 "칠판" 카드, 카테고리마다 다른 4색

**목표:** 같은 기능을 유지하면서, "기본값을 그대로 쓴 AI 앱"이 아니라 의도를 갖고 다듬은 앱으로 보이게 한다.

**레퍼런스:** Coinbase iOS 앱 — 순백 배경, 거의 검정 글자, 포인트는 최소, 카드 대신 얇은 구분선 리스트, 큰 굵은 숫자/제목, 선 아이콘. 분위기와 규칙만 빌리고 브랜드(로고, 파랑)는 가져오지 않는다.

## 목표 / 비목표 / 반목표

**목표**
- 색·폰트·아이콘을 아래 규칙으로 앱 전체 통일
- 식단 화면의 날짜 이동, 메뉴 배치, 식사시간 표시를 다듬음

**비목표**
- 탭 구성 변경(5개 그대로: 식단 / 희망메뉴 / 자유 / 즐겨찾기 / 마이)
- 데이터·API·Supabase 쿼리 변경
- 새 기능 추가 (아래 "남은 시간 표시", "지난 끼니 흐리게"는 예외로 합의됨)

**반목표 (이러면 실패)**
- 베이지/누런/크림 톤이 어디든 남아 있음
- 이모지가 UI에 하나라도 남아 있음
- 빨강이 좋아요 외의 장식으로 쓰임
- 다른 유명 앱(Coinbase 등)을 그대로 베낀 것처럼 보임

## 공통 컴포넌트 규칙

- **카드 → 구분선.** `rounded-2xl border bg-surface p-4` 박스 리스트는 박스를 없애고 항목 사이 1px `border` 선으로 나눈다. 그림자·hover 갈색 그림자(`rgba(118,85,42,...)`) 제거.
- **선택 상태는 검정.** 탭바, 칩, 요일, 마이페이지 탭 모두 `primary`(검정) 배경 + 흰 글자, 또는 검정 글자 + 굵게.
- **하단 탭바:** 선택 탭의 초록 알약 배경 제거. 선택 = 검정 아이콘(stroke 2.4) + 굵은 라벨, 비선택 = 회색. 아이콘은 현재 그대로(`Soup`, `MessageCircleHeart`, `MessagesSquare`, `Heart`, `User`).
- **헤더:** 로고 `DormEats`를 Pretendard 800, 검정으로. `Soup` 아이콘도 검정.
- **좋아요/하트:** 이모지 ❤️/🤍 → Lucide `Heart`. 안 눌림 = 회색 선, 눌림 = `like` 색으로 채움. 좋아요 수 옆 하트도 동일.
- **카테고리 칩(자유게시판):** `lib/categories.ts`의 카테고리별 4색 제거. 칩은 회색 배경(`accent-soft`) + muted 글자, 선택 시 검정. 글 목록의 카테고리 라벨은 색 배경 없이 muted 굵은 글자(예: "식당 밥 같이 먹을 사람").
- **빈 상태:** 점선 박스 제거. 가운데 정렬 회색 원 안의 Lucide 아이콘 + 굵은 한 줄 + 회색 안내 문구 (+ 필요 시 테두리만 있는 버튼).
- **오류 화면:** "오류 발생 😢" → 이모지 제거, "오류가 발생했어요" 같은 문구.
- **회원가입 상단 "🍚 도봉학사 식단 커뮤니티":** 이모지 제거.

## 화면별 변경

### 식단 (`app/page.tsx`)

**날짜 영역 (토글 대체)**
- 상단: 작은 라벨(13px, 700, muted) + 큰 제목(26px, 700) "10월 26일 월요일".
  - 라벨은 선택한 날이 오늘/내일/모레/어제일 때만 "오늘"/"내일"/"모레"/"어제", 그 외엔 라벨 없음.
- 그 아래 요일 띠: 이번 주 월~일 7칸. 각 칸 = 요일(작게) + 날짜 숫자(원 안). 선택된 날 = 검정 원 + 흰 숫자. 오늘 = 숫자 아래 작은 점.
- 오늘(정확히는 아래 effectiveDate)이 아닌 날을 보고 있으면 제목 오른쪽에 테두리 알약 버튼 "오늘로".
- 처음 열 때 선택되는 날은 지금 로직의 `effectiveDate` 그대로 (저녁 끝나면 내일). 이때 라벨은 "내일"로 정직하게 표시.
- 삭제: `view` 상태('today' | 'week') 와 토글 버튼, 아래 "도봉학사" 줄, "내일 메뉴로 자동 전환됐어요" 문구.
- 유지: 주 범위, 쿼리, 펼친 끼니(`expandedMeal`) 동작.

**끼니 (접힘/펼침 구조 유지)**
- 접힌 끼니: 박스 제거, 구분선 행. "아침 07:00 ~ 08:30" + 메뉴 미리보기 + 오른쪽 `ChevronRight`.
- 펼친 끼니: 초록 배경 박스 제거. 제목 18px 굵게 + 시간.
- **메뉴 2열은 하나의 CSS grid(`grid-cols-2`)로.** 지금처럼 왼쪽/오른쪽 열을 따로 쌓지 말 것(`leftItems`/`rightItems` 제거). 순서는 가로로 1·2 / 3·4 … 각 메뉴는 박스 없이 아래 구분선, 부가 설명(`detail`)은 11px muted.
- 후기 줄(`ReviewSection`): 노란 별 → 검정 별, 링크는 검정 굵게.

**식사시간 표시 (지금 "지금 식사시간"/"식사 준비 중" 배지 대체)**
- 현재 식사 중인 끼니: 제목 줄 오른쪽에 `● 지금 · 40분 남음`. 점은 검정, 천천히 깜빡임(opacity 펄스). "지금"은 굵게, "· 40분 남음"은 muted.
- 식사 사이(다음 끼니): `3시간 30분 후` (muted, 600). 알약/테두리 없음.
- 접힌 끼니에도 같은 문구를 시간 옆에 작게.
- 남은 시간 = 식사 종료 시각 − 지금 / 다음 끼니 시작 − 지금. 끼니 시각은 `lib/date.ts`의 값과 같음. 1시간 미만은 "N분", 이상은 "N시간 M분"(M=0이면 "N시간").
- 화면을 켜 둔 채 시간이 지나도 갱신되게 1분 간격 갱신 (빌더 재량으로 구현).
- 이 표시는 오늘(effectiveDate)을 보고 있을 때만.

**지난 끼니 흐리게**
- 오늘을 보고 있을 때, 종료 시각이 지난 끼니는 제목·시간·미리보기를 opacity ~45%로. 누르면 펼쳐지는 동작은 그대로.
- 저녁 이후 내일로 자동 전환된 상태에선 내일 끼니는 흐리지 않음.

**하단 희망메뉴 1위**
- 유지: 1위 글 하나, 제목 + 본문 2줄 미리보기 + 작성자·상대시간 + 좋아요 수, "전체보기 ›".
- 변경: 섹션 제목 "희망메뉴 인기"(📌 제거), 기울어짐(`rotate(-0.6deg)`) 제거, 초록 배경 박스 제거, "TOP 1 🔥" 배지 → 굵은 큰 숫자 "1", ❤️ → Lucide 하트(`like` 색, 채움), "Community" 영문 라벨 제거.

## 검토 후 확정된 사항

**사용자 확인 완료**
1. **`--danger`(오류·삭제 문구)는 빨강 유지.** "빨강은 좋아요만" 원칙의 유일한 예외. 장식이 아니라 기능 색이므로 반목표에 해당하지 않음.
2. **다크 모드는 유지**하고 흑백 반전(검정 배경·흰 포인트). 토큰 표의 다크 값 사용.
3. **희망메뉴·마이 글 목록은 2열 카드 → 1열 구분선 리스트.**
4. **`app/week/page.tsx` 삭제.** 요일 띠가 같은 역할을 함. 삭제 전 `/week`로 가는 링크가 정말 없는지 다시 확인.

**Claude 판단 (날짜 기준 통일)**

용어: **실제 오늘** = 서울 기준 오늘 날짜. **기본 날짜** = 지금 코드의 `effectiveDate`(저녁 끝나면 내일).

| 기능 | 기준 |
|---|---|
| 요일 띠가 보여주는 주(월~일) | **기본 날짜가 속한 주.** 일요일 저녁 이후엔 다음 주가 보임(실제 오늘 칸이 띠에 없어도 됨). 쿼리 범위도 이 주에 맞춤. 주 넘기기 기능은 추가하지 않음 |
| 띠의 "오늘 점" | **실제 오늘** (띠에 없으면 점 없음) |
| 제목 위 라벨(오늘/내일/모레/어제) | **실제 오늘** 기준 |
| 처음 선택되는 날 | 기본 날짜 |
| "오늘로" 버튼 | 선택한 날 ≠ 기본 날짜일 때 표시, 누르면 기본 날짜로 |
| 남은 시간 표시 | 기본 날짜를 보고 있을 때만. 저녁 이후 내일을 보고 있으면 내일 아침에 "10시간 30분 후"처럼 표시(자정 넘겨 계산) |
| 지난 끼니 흐리게 | 선택한 날 = 실제 오늘일 때만, 종료 시각 지난 끼니. 내일로 넘어간 상태에선 흐린 끼니 없음 |

**그 밖의 Claude 판단**
- 데모가 없는 화면은 공통 규칙만 적용하고 레이아웃은 건드리지 않음.
- `--faint` 토큰 추가: 라이트 `#8a919e`, 다크 `#6b7280` (섹션 라벨, 보조 시간, 비활성 아이콘).

## 빌더에게 맡기는 것

- Pretendard 로드 방식
- 남은 시간 갱신 구현(타이머/훅)
- 깜빡임 애니메이션 세부 값
- 컴포넌트를 공통으로 뽑을지(빈 상태, 하트 등) 여부
